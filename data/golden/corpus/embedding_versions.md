# Embedding 版本与索引迁移

## Shared vector space

查询向量与文档向量必须来自兼容的表示空间。两个编码模型即使输出相同维度，也不能因此直接混用；坐标轴含义与训练目标可能已经改变。索引元数据应记录模型标识、版本、维度、距离和归一化约定，查询服务在不匹配时明确拒绝或切换版本，避免返回看似合法却无意义的近邻。

## Migration procedure

更换 embedding 模型时，可离线为完整语料生成新向量并构建独立索引，验证覆盖率与检索指标后再切换查询编码器和索引。切换应以同一版本指针原子生效，并保留旧版本用于回退。逐批覆盖原索引会在迁移窗口混合不同空间，除非系统明确隔离版本，否则容易出现不可解释的排名波动。

## Fake embedder scope

确定性 FakeEmbedder 适合离线测试向量维度、批处理、排序稳定性与接口错误传播，无需密钥或网络。基于哈希桶或手写词表的假向量没有真实语义理解能力，其近邻质量往往由碰撞或词面规则决定。用它比较检索管线可以发现接线问题，却不能证明自然语言改写在生产模型上有良好召回。
