# asyncio 协作调度与阻塞

## Event loop cooperation

asyncio 事件循环在协程等待可挂起的操作时调度其他任务。async def 只是声明协程函数，函数内同步读取文件、调用阻塞客户端或长时间计算仍会占用事件循环线程。高并发服务中，一个这样的操作就可能延迟其他请求；应使用异步客户端，并把不可避免的阻塞调用交给受控线程池或独立工作进程。

## Concurrent tasks

创建多个 Task 可以让独立的 I/O 等待交叠，但不能让同一线程上的纯 Python 计算自动并行。任务数量也不等于吞吐，过量任务会增加内存和调度成本。批量访问外部接口时应设置并发上限、复用客户端连接并观察队列等待；不要为每个输入无限制创建任务后把所有压力推给下游。

## Resource cleanup

异步连接和响应流应使用异步上下文管理或可靠的 finally 路径释放。请求失败时只捕获业务异常，并保证退出路径能关闭流、归还连接与停止子任务。资源泄漏可能先表现为偶发排队，再演变成连接池耗尽；检查延迟时需要把等待空闲连接的时间与真正的远程响应时间分开记录。
